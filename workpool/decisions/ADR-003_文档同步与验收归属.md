# ADR-003 文档同步与验收归属

日期：2026-10-30。状态：采纳。架构owner：Codex。后续代码集成owner：Grok。

用户要求必要修复、统一文档口径，并明确实际产品代码由Grok施工。本ADR只调整文档与任务归属，不修改src、tests、migrations、依赖或运行数据。

## 决定

1. 产品白皮书2.1保持锁定。技术1.1五处1–4与一处最多4统一为单运行最多三职责，四职责链拆关联运行并由用户确认澄清；同时统一状态机、幂等/追踪、服务器预览、上传路径、事件与下载授权。
2. 技术/UI页面/UI白皮书保持既有文件名版本并标记2026-10-30勘误版，修正文稿与Word，架构负责人定向同步三份reference。编码代理仍只读reference。备份与新哈希单独留档，旧审计/清单保持历史。
3. T01 done仅对应G0基础基线。生产认证隔离属于T02，显式转移并保持未实现/未测。不是降低最终P0安全验收；G1及T02必须补证。
4. Codex负责架构、文档裁决和验收监督；Grok负责产品代码总控及唯一代码集成，普通实现选择自主推进。开发期四代理槽与产品AgentRun三职责限制分开。
5. 安全瘦身统一为指定343项可恢复归档和D盘局部清理；5.13MiB是逻辑体积差，不是磁盘可用空间净释放实测。旧C暂存/环境/缓存仍保留，本轮不删除用户或旧施工资料。

## 验证

本轮检查修订MD/Word文本同步、R05四列完整、三职责约束、协议字段、目录/schema/任务归属及产品代码哈希不变。Word必须渲染检查。本轮不将文档修复写成代码功能完成，也不把历史66项测试记作本轮业务测试。
