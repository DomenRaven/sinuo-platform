# ADR-002 基础事务、租约与执行边界加固

日期：2026-10-30。状态：采纳；Owner：Codex（集成）。范围：T01 基元，不变更产品定义。

独立审查发现：底层 Connection.commit 可绕过 Session 的提前提交保护；非法预算可突破 semaphore；分层 gather 会阻塞已就绪下游；非标准 JSON 与失效租约可被接收。

决定：write_uow 同时拦截托管 Session/Connection 的提前 commit；处理器只使用 Session 数据操作，不直接使用原生 DBAPI 或事务 SQL。连接/Session 的事务均须保持原事务存活。失败时回滚。该保护用于发现实现错误，不是对任意恶意 Python 代码的隔离。

DAG 按 FIRST_COMPLETED 重调度依赖，保留单协调器发布及最多三职责。并发数只接受整数，期限必须有限。Provider 需合作取消、使用有界传输；内存 runner 不提供对任意阻塞代码的进程隔离。严格 JSON 拒绝重复键、NaN、Infinity 和数值溢出。

追加 0002_lease_invariants，不改已交付 0001。升级拒绝非法旧租约并给出诊断，合法数据保留；允许降回 0001。leased 要有非空 owner、有限 expiry、正 fence；pending/delivered 的租约字段须为空。应用同时拒绝无效时间、时间加法溢出及不可表示的正租期。

验证：tests/test_foundation_boundaries.py，集成后以交接报告中的实际结果为准。本 ADR 不代表持久 AgentRun、业务 ACL 或完整 P0 已实现。
