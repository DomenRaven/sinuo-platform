## 可用代码与限制

| 可用部分 | 消费方式 | 边界 |
| --- | --- | --- |
| Settings | `sinuo.config.Settings` | SINUO_ 配置，模型默认关闭、密钥 SecretStr；身份设置待 T02 |
| engine/UoW | `build_engine`、`write_uow` | SQLite WAL/FK；请求/任务独立 Session；短 BEGIN IMMEDIATE；标准 Session/Connection 提前 commit 拒绝 |
| 幂等命令 | `execute_idempotent` | 当前授权回调每次调用；命令/效果/Outbox/回执同事务；真实 ACL 由 T02/T04 接入 |
| 投递租约 | `claim_delivery`、`complete_delivery` | 有限时刻、状态一致性、递增 fence；工作事务外，完成与效果同事务；统一 DB 时钟/renew 由 T06 接线 |
| 内存 DAG | `DagRunner` / ModelProvider | 四选最多三职责，整数并发、有限期限、依赖就绪即调度、严格 JSON、迟到拒绝；持久运行/外发网关仍属 T08 |
| HTTP | `/healthz`、`/readyz` | ready 仅 scope=foundation；OpenAPI 只有这两个端点 |

UoW 仅提供可信代码的事务边界。处理器禁止原始事务 SQL、直接 DBAPI 与分拆同一命令的独立连接。Provider 必须使用有界 I/O 并合作取消；内存 runner 不隔离任意阻塞 Python 代码。

`0001_primitives` 原文保留，追加 `0002_lease_invariants`。升级保留合法回执/事件/租约；非法旧租约先诊断失败，不静默修改，维护者核验后处理。迁移单一 head；T03 从 0002 之后追加，不改已交付迁移。
