# 用户决定：课程范围（2026-11-01）

用户当面逐条给出。本文件只记录范围，不把任何任务标成 done，不签 G0–G4。

对照的是白皮书第 3.1 节的八个阶段、第 6 节的 F 编号，以及第 4.1 节的两层图。已有的 3D 决定仍见 `USER_WAIVE_3D.md`。本文件把缩略图也从必须项里拿掉。

## 总览是不是界面

是。F02 里“总览画面”是界面。

后端要保证的是：同一阶段可以有两张页，系统不自动把它们连成前后关系。这件事已有测试。白皮书第 3.3 节和第 4.1 节说的项目总览，是设计负责人打开后看到的页与页的路径。那一层画面属于界面，不记成后端缺口。

## 必须做的后端和可见过程

| 条目 | 决定 |
| --- | --- |
| F01 | 先做一份固定的产品设计模板，不做成可随便增删的模板库。阶段名称就用白皮书第 3.1 节的八个：任务与情境、用户与场景研究、问题及机会定义、设计要求、概念探索、深化与原型、测试与迭代、表达与复盘。阶段可以重排、跳过或返回，但名字先用这一套。 |
| F03 | 页内节点要做全：问题、证据、洞察、要求、作品、测试、决定。每一类标明负责的智能体职责。工作过程要能看见。模型只提议，确认仍由人做。 |
| F04 | 完整实现。新阶段页记下确切来源版本；分叉和合流都要有。 |
| F05 | 完整实现。旧版本只读；从旧版本继续时新开页或新版本；原来的路线还在。 |
| F08 | 完整实现。从方案能回到要求和原始证据；测试钉在某一个作品版本上。 |
| F09 | 完整实现，并且过程可见。建议含理由、缺口、来源和版本。系统不能自己翻阶段。关闭、手动、事件后、定时摘要都要有效。 |
| F10 | 完整实现，并且运行过程可见。记下输入版本、路由、工具调用、错误和人的改正。 |
| F16 | 完整实现，并且选人过程可见。问资料、问方法、问下一步、简报变化走不同职责。没被选中的职责不耗调用。 |
| F17 | 完整实现，并且出处可见。关键判断要有文件版本，以及页码、时间点或区域。没有证据时说明缺口。 |
| F18 | 完整实现，并且方法卡可见。写清问题、输入、步骤、局限和课程或文献来源。 |
| F19 | 完整实现，并且候选可见。智能体只生成候选。确认前，正式的页和阶段不变。 |
| F20 | 完整实现，并且分层可见。会话、手头任务、已确认事实、可重建摘要分开。过时结论退出默认检索。 |

职责对照白皮书第 3.1 节“AI 可提供的帮助”，四个职责仍是澄清、证据、方法、过程批评：

| 阶段或节点 | 负责职责 | 人留下的决定 |
| --- | --- | --- |
| 任务与情境、课题边界 | 澄清 | 确认范围 |
| 证据、洞察、用户研究材料 | 证据 | 选择解释 |
| 方法卡、概念路径、测试计划 | 方法 | 选择保留哪条 |
| 要求是否可测、阶段建议、缺口 | 过程批评 | 确认进入、修改或返回 |
| 作品、测试记录、决定 | 不由模型写入 | 人确认后才落正式记录 |

## 明确不做或降级

- 3D、GLB 和其他三维转换继续不做。见 `USER_WAIVE_3D.md`。
- 缩略图不是必须项。文件名要能看出这是哪一版作品。不支持的格式保留原件下载。不为了缩略图或手贴封面再开一条施工。
- F02 的总览画面留给界面，不在本决定里要求先做页面。

## 真实模型

设计智能体要能真正使用，并接入 DeepSeek。证明这条能力的测试要真实调用 API。

控制逻辑仍可用假模型。假模型通过不能代替真实调用。密钥只放在本机 `.env`，不写入仓库、交接、日志或测试输出。`live_model` 是这条证明的标记，不能再用“未跑真实模型”当作完成。

澄清和证据用 `SINUO_MODEL_NAME`。方法和过程批评用 `SINUO_MODEL_NAME_REASONING`。模型不提交业务。

## 理论库

课程理论仍以本机 `F:/工业设计理论库` 为底，导出到 git 忽略的 `var/theory`。不要把课件原文复制进 git。

没有找到一份专门覆盖工业设计全流程、又可整库下载的方法数据库。下面这些可以按许可证增补方法卡。教材和标准不要整本下载。

| 来源 | 许可证 | 能否纳入思诺语料 |
| --- | --- | --- |
| [18F Methods](https://github.com/18F/methods) | CC0，公有领域。仓库已归档，正文转到 guides.18f.org | 可以。方法卡要保留来源名 |
| [Open Design Kit](https://github.com/open-design-kit/opendesignkit) | CC BY 4.0 | 可以改写进方法卡，须署名 |

| Hyper Island Toolbox | 保留所有权利 | 不下载、不入库 |
| Service Design Toolkit | 页面写明知识共享，具体条款要以下载页为准 | 未核对具体条款前不复制正文 |

增补的方法卡仍然要带 `library_key`、`course` 或来源名、`page_id`、`chunk_id`、来源路径和正文哈希。检索仍先按身份过滤。向量和图检索函数继续吃调用方给的 JSON，不改成直接读 F 盘或这些网站。
