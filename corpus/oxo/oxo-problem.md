# 金属削皮器的握持问题

细硬金属柄在湿手和握力不足时打滑、疼痛，削某些食材又离不开这件工具。

Cooper Hewitt整理的过程说明写到，Farber通过研究和观察认识到：已有削皮器在潮湿时难用，关节炎或握力有限的人难以握住，而准备某些食物又需要削皮。他自己的话被馆藏转述为，普通厨房工具会弄痛手，剪刀环痛，细硬把手也痛。问题因此不是刀刃不够锋利这一句就能说完，而是手、水、力和工具截面叠在一起。没有这些证据时，不能把结论写成某一种把手必然正确。关键词：问题定义、湿滑、细柄、握力。

来源口径：Cooper Hewitt馆藏与过程说明、US4974286 / USRE34194、Smart Design公开记述、Santoprene厂商注塑指南、通用设计中心的公开定义。正文是依据这些公开材料写成的检索摘要，不是原文摘录。
