# 二、硬性要求（必须遵守）

1. **你是用户，不是开发者**：所有动作都发生在浏览器 UI 里。观察页面、等它加载、看它给你的反馈，再继续下一步。不要“跳步”，不要用后端接口代替 UI。
2. **先录屏、再操作**：在登录之前就先把录屏开起来，保证素材从第一个像素开始完整。
3. **模拟真人节奏**：每一步操作之间停顿 0.5–1.5 秒；上传文件、提交后等它的反馈提示出现再继续。不要一口气连点。
4. **智能体回复要等 + 要滚到底**：每次在对话里提问后，智能体运行需要 30–90 秒，必须**等「待确认」候选卡或回复角色卡出现**才算完成。**由于页面较长，智能体的回复和「待确认」候选卡通常在页面底部，每轮提问后都要把页面滚动到最底部才能看到完整内容。** 看不到就再往下滚。
5. **智能体建的页标题措辞可能略有出入**：只要看到候选卡正文是「将创建：…」且目标是一个空白新页，就照常点「预览」再「确认」，不要纠结标题是否与下文一字不差。
6. **全程留日志**：每完成一个阶段，记录做了什么、结果如何；遇到任何异常（弹窗报错、卡住、超时）如实记录，不要掩盖。
