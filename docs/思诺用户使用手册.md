# 思诺（Seno）用户使用手册

> 版本：v1.0 · 2026-11-02
> 适用：思诺智能体辅助设计平台（本地演示版）

思诺是一个面向工业设计课程项目的 AI 辅助设计与过程管理平台。它用「书 · 章 · 页 · 节点」把设计过程组织成可解释、可回溯的结构，让四位智能体与你协作查证、建议、检查，而**决定始终由你做出**。

## 1. 认识思诺

### 1.1 一句话

思诺把「一个设计项目」当作「一本书」来组织：**书（项目）→ 章（阶段）→ 页（探索）→ 节点（推理）**。每一层都可展开、可回溯，AI 的建议和你的决定都能回到确切的版本与依据。

### 1.2 四位智能体

一次运行由至多三位智能体协作，结论由你确认：

| 职责 | 它做什么 |
| --- | --- |
| **课题澄清** | 界定课题边界，收敛成清晰的问题陈述 |
| **证据查找** | 检索资料、提炼洞察，为每个要求找到依据 |
| **方法建议** | 推荐研究、验证与表达的方法 |
| **过程检查** | 检查要求与缺口，给出下一步建议 |
| **由人确认** | 你本人：查看差异、确认或拒绝，最终决定 |

### 1.3 书 · 章 · 页 · 节点

- **书（项目）**：目标、成员、阶段模板、权限与成果摘要。
- **章（阶段）**：一个设计活动阶段，共 8 章（任务与情境、用户与场景研究、问题及机会定义、设计要求、概念探索、深化与原型、测试与迭代、表达与复盘）。
- **页**：同一阶段里的一个独立探索或方案。同章页彼此**平行**，不强制串行。
- **节点**：页内的推理单元。当前开放七类：问题、证据、洞察、要求、作品、测试、决定。素材和概念仍在白皮书第 4.1 节的对象模型里，没有进入 2026-11-01 的范围决定，也没有进入施工合同 WAVE_F03。

## 2. 快速开始

1. 打开浏览器访问平台地址（本地演示：`http://127.0.0.1:8000`）。
2. 在登录页输入账号与密码，点击 **登录**。
3. 登录后进入 **项目书架**，选择或新建一个项目。

> 演示账号：`synthetic-lead` / `synthetic-pass-lead`（负责人角色）。

---

## 3. 项目书架

登录后的首页是项目书架，包含三块：

- **智能体**：四位智能体的能力概览卡片。
- **你的项目**：你可见的项目列表，点击进入该项目。
- **新建项目**：填写「课题名称」，点击 **建立项目**。新项目会从第一个阶段开始。

---

## 4. 项目地图：章与页

进入项目后，你会看到**项目地图**——这是项目的可视化总览，包含：

- **设计流程**：8 个阶段的横向流程条，有内容的阶段会高亮。
- **设计进度**：各阶段已开启页数的横向条形图。
- **章页画布**：项目的核心结构图（见下）。
- **每个阶段的智能体**：阶段 × 职责分工矩阵。

### 4.1 章页画布

章页画布把「章」画成泳道，「页」画成缩略图卡片：

- **章**：蓝色渐变色块章头，标注「第 N 章」与章名、页数。
- **页缩略图**：每页一张卡片，显示页标题与状态；点击卡片进入该页的工作区。
- **承接连线**：跨章的蓝色虚线箭头表示「由何而来、走向何处」（来源关系）。
- **同章平行**：同一章里的页彼此平行。

### 4.2 拖拽重排页

- 抓住页缩略图底部的「⠿ 拖拽」把手，拖动可**重排顺序**，或**移到其他章**。
- 拖拽只调整画布布局（浏览器本地记住），**不改变页所属的阶段**，也不影响任何已确认内容。

## 5. 单页工作台

点击页缩略图进入单页工作台。页面自上而下：

1. **面包屑与标题**：项目 / 章 / 页的定位路径。
2. **版本徽章**：显示「已确认第 N 版」或「进行中草稿 R…」。
3. **页内推理图**：这一页的所有节点按推理顺序排成链条（左侧圆点 + 竖线连接），节点卡片显示类型、内容与状态，点击任一节点即可编辑。
4. **工作台**：左右两栏分区。

### 5.1 工作台左右分区

| 左栏 · 你的工作 | 右栏 · 智能体工作 |
| --- | --- |
| 写节点 | 本次读取范围 |
| 中间交付物 | 快捷提问 |
| 确认为正式版本 | 运行轨迹 · 待确认候选 |

左侧是你**亲手**做的事，右侧是智能体**协助**做的事——分工一目了然。

## 6. 写节点

在左栏「写节点」区：

1. 选择节点类型：**问题 / 证据 / 洞察 / 要求 / 作品 / 测试 / 决定**。
2. 在「内容」输入框写下这个节点的内容（例如：`用户夜间取物时希望少移动、少开灯`）。
3. 点击 **记下这个节点**。

节点会出现在「页内推理图」中，按推理顺序排成链条（问题 → 证据 → 洞察 → 要求 → 作品 → 测试 → 决定），颜色表示产出它的角色（问题→课题澄清、要求→过程检查、证据/洞察→证据查找、作品/测试/决定→由人确认）。

### 6.1 编辑与删除节点

点击「页内推理图」里的任意节点卡片，会弹出编辑窗口：

- **保存**：修改内容后保存。
- **删除**：移除这个节点。
- **问智能体**：把该节点带入右侧对话（见第 9 章），自动预填「查证据：…」，回车即可让证据查找智能体围绕它查证。

### 6.2 节点之间的关系边

在「页内推理图」里，节点之间可以连上**带类型的关系边**，把一条推理链变成真正的推理网：

1. 按住某个节点卡片右侧的 **↗ 把手**，拖到另一个节点上松开。
2. 在弹出的选择里选一种关系：**承接 / 支持 / 反例 / 引用**。
3. 关系边会显示在来源节点卡片底部（例如「承接 → 要求」），点击边上的 **×** 可删除。

这些关系边会随草稿一起保存，确认版本后，智能体读集时就能看到节点之间的承接与冲突关系。

智能体（过程检查）在运行时若发现节点之间存在明显的承接/支持/反例/引用关系，也会主动提出一条「新增关系」候选，显示在右栏「待确认」里（标注关系类型），你预览确认后即写入草稿。

> 提示：先记下内容，再固化版本，之后才能向智能体提问。

---

## 7. 中间交付物

在左栏「中间交付物」区上传作品（草图、照片、模型、测试记录等）：

1. 选择文件，填写**许可**，选择**敏感范围**（项目内 / 敏感 / 可对外）。
2. 勾选「允许以后的运行读取这份原件」以允许智能体引用它。
3. 点击 **上传原件**。

上传后作品按版本沉淀为交付物卡片。每个文件以原件 + 元数据 + 可选预览组成，测试记录会绑定到确切的作品版本。

---

## 8. 固化版本

草稿与正式版本是两条状态线。在左栏「确认这一版」区点击 **确认为正式版本**，把当前草稿固化为不可变的正式版本，作为后续新页的展开起点。

- 草稿可随时修改；固化后生成一个新的版本号。
- 历史版本只读，可随时回看。

---

## 9. 智能体工作台

右栏是智能体的工作区。

### 9.1 本次读取范围

- 展示当前页版本、可读取的资料来源（本页内容、项目内证据、理论库、方法卡）。
- 可勾选「纳入邻页」「纳入作品」，或「跳过理论库 / 方法卡」。
- 勾选只影响**下一次**运行，不改已确认的事实。

### 9.2 快捷提问

四个快捷动作：

| 动作 | 触发 |
| --- | --- |
| 澄清课题 | 界定课题边界 |
| 找依据 | 检索资料，生成洞察 |
| 选方法 | 推荐合适的方法 |
| 检查下一步 | 检索证据，判断下一步 |

> 需先「确认为正式版本」，才能提问。

### 9.3 运行轨迹

提问后，工作台会展示这次运行：

- **你的提问**（意图）
- **工具调用链**（检索证据 / 检索理论 / 读取页快照）
- **角色卡**（按依赖次序展示各智能体的结论与依据）
- **依据**：每条结论可溯源到具体来源
- **缺口**：待补充的项

### 9.4 候选确认

智能体产出的「待确认」候选卡：

- 点击 **预览**，查看即将改动的内容。
- 点击 **确认**：由领域服务校验权限、版本、幂等后提交，可能新建下一页。
- 点击 **拒绝**：只记录处置，不改变业务对象。

---

## 10. 版本回溯与分支

从历史版本出发，有两条只写路线（正常回溯**不删除**历史）：

1. **从旧版创建分支**：创建新页并继承旧版可编辑内容，旧决定与测试仅作历史依据。
2. **确认进入下一章**：创建主体空白的新页，只带入你明确选择的引用。

时间轴上谱系按创建时间向前，保持无环；可回返，不覆盖另一条路线。

---

## 11. 提示与说明

- **先固化、再提问**：智能体运行绑定已确认的页版本，未固化前不能提问。
- **读取范围只在本次生效**：切换浏览线或勾选资料，只影响新的运行，不改已确认事实。
- **拖拽只是布局**：页缩略图拖动是画布布局（本地记住），不是业务事实。
- **来源可回溯**：每条关系、每个结论都带类型、作者、时间与可查看的依据。
- **安全边界**：智能体不直接写业务库，只有经你确认后由领域命令服务提交。
