# 思诺智能体辅助设计平台 UI 页面实施规范

**版本：1.1 勘误版｜2026 年 10 月 30 日**  
**依据：已锁定的产品白皮书 2.1；配套技术实施规范 1.1 与 UI 白皮书 1.3**  
**性质：逐页实施合同，路由、字段和状态尚未在 D/E 旧系统中验证**

## 1 界面必须区分的四个坐标

一次 UI 会话同时有四个独立坐标，不能把它们压成“当前页”一个变量：

1. **导航位置**：`project_id / stage_id / page_id`。章是阶段容器；同章页默认平行。
2. **业务读版本**：`page_version_id` 表示不可变确认快照；活动草稿另带 `draft_content_revision` 与内容哈希。历史版只读，切换浏览位置不改项目当前版。
3. **AI 本次上下文**：运行时固定 `input_page_version_id`（已确认基底）、可选 `input_draft_content_revision`、纳入的邻页版本、证据锚点、作品版本、方法卡版本和权限快照。改变勾选只影响下一次运行，不改项目权威记忆。
4. **对象焦点**：`node_id / edge_id / evidence_anchor_id / artifact_version_id / run_id`。抽屉和深链指向对象及版本，不能只靠画布坐标定位。

全局顶栏始终显示项目、章、页、分支标签、业务版本（“进行中草稿 R7”或“已确认第 3 版”）、保存状态和 AI 运行状态。打开历史版时显示“历史版本·只读”横幅及“返回当前版”“从此版创建新路线”，但绝不出现会覆盖当前版的“恢复”。版本切换是读操作，分支创建才是写操作。浏览器前进/后退须恢复准确位置、筛选和对象焦点；不得造成版本写入。

章历史以 `project_revision` 选择项目时间点，页历史以 `page_version_id` 选择不可变快照，节点历史投影同页各版中的 `node_id`。章视图读取当时配置、页版本和来源边，切换时间点不改当前项目。

### 1.1 共享组件及数据属性

| 组件 | 最小字段 | 行为与边界 |
| --- | --- | --- |
| `ProjectHeader` | 项目 ID、标题、角色、当前任务、保存状态 | 所有项目页共用；权限变更时刷新可用动作 |
| `StageRail` | `stage_id`、阶段顺序、活动状态、页数 | 点击切换章，只改变导航；阶段顺序不推导页间因果 |
| `PagePathGraph/List` | 页 ID、版本 ID、状态、类型化页边、可见范围 | 默认树状布局，合流仍显示多条边；图和列表共享键盘导航 |
| `PageVersionPicker` | 当前版本、历史版本、`draft_content_revision`、分支起点 | 明确“浏览”与“从此版继续”；切换浏览不改正在运行的 AI 快照 |
| `NodeGraph/List` | 节点 ID、类型、状态、主树边、辅助边 | 拖动坐标只存视图布局；添加/撤销业务边必须显式操作 |
| `ObjectInspector` | 对象 ID、所属版本、作者、时间、来源、权限 | URL 可深链；无权限对象只显示限制说明，不显示标题/缩略图/片段 |
| `EvidenceLink` | 锚点 ID、原件版本、页码/时码/区域、支持关系 | 失效源显示原位置与失效状态，不改指另一版本 |
| `ArtifactCard` | 原件版本、MIME、哈希、预览状态、封面来源 | 原件已保存与预览可用分开；预览失败保留下载与手动封面 |
| `AgentWorkbench` | run ID、输入快照、资料范围、步骤、预算、候选 | 运行进度用步骤和卡片，不把流式 token 当已确认事实 |
| `CandidateCard` | proposal ID、来源、缺口、变更清单、有效期、处置 | 候选已校验且 `status=pending`、当前具权时可预览；提交只引用已保存预览，过期重检 |
| `ContextScopePanel` | 记忆层、纳入对象及版本、估算大小、敏感级别 | 本次运行读集可调整；不能勾选未授权对象，也不改权威记忆 |
| `ReviewOpinion` | 作者、版本/节点锚点、时间、可见范围 | 与业务图改写分开，非作者或无权者不能编辑既有意见 |

### 1.2 路由与弹层原则

以下为稳定 URL 语义，具体前端框架可替换；R05 的 `view` 参数取 `graph` 或 `list`，表中以 `graph` 举例。路径参数用不可变 ID，不用标题；`v` 为历史快照 ID，省略时进入当前活动版；`panel` 为可深链的侧抽屉。返回路径用路由状态保存，不能由浏览器历史猜测。

| 编号与优先级 | 路由 | 页面责任 | 从哪里进入 / 主要出口 |
| --- | --- | --- | --- |
| R01 P0 | `/projects` | 项目书架与待处理项 | 登录后 / 进入项目、创建项目 |
| R02 P0 | `/projects/new` | 项目建立向导 | 书架 / 创建后项目总览、取消回书架 |
| R03 P0 | `/projects/:p` | 项目概览、页路径图与列表 | 书架、面包屑 / 章、页、资源、审阅 |
| R04 P0 | `/projects/:p/stages/:s` | 章概览与平行页集合 | 目录、项目总览 / 页工作区、新建平行页 |
| R05 P0 | `/projects/:p/pages/:g?v=:v&view=graph` | 单页探索与历史只读视图 | 章卡、搜索、路径边 / 对象抽屉、历史、AI 运行 |
| R06 P0 | `/projects/:p/pages/:g/history` | 版本时间线、分支谱系和文本差异 | 页版本选择器 / 历史版、当前版、创建新路线 |
| R07 P0 | `/projects/:p/artifacts` | 可视化文件视图与上传队列 | 项目导航、节点 / 原件详情、返回引用页 |
| R08 P0 | `/projects/:p/artifacts/:a/versions/:av` | 作品原件版本详情 | 资源卡、证据链接 / 下载、引用节点、旧版 |
| R09 P0 | `/projects/:p/search?q=...` | 权限过滤的全局结果 | 顶栏 / 精确对象、原页 |
| R10 P0 | `/projects/:p/agent/runs/:r` | 运行轨迹与候选详情 | 工作台、待办、审阅 / 来源、确认预览、返回原页 |
| R11 P0 | `/projects/:p/context` | 项目记忆目录与本次运行读集检查 | 页工作台“本次将读取”、项目导航 / 对象来源、返回运行 |
| R12 P0 | `/projects/:p/review` | 授权审阅路径与意见 | 项目概览、通知 / 锚点、原版本、意见 |
| R13 P0 | `/projects/:p/export` | 导出范围、来源索引与审校 | 项目导航 / 下载结果、返回项目 |
| R14 P0 | `/projects/:p/settings` | 成员权限、阶段模板、建议频率 | 项目菜单 / 返回项目；危险操作独立确认 |
| R15 P1 | `/projects/:p/compare?left=:v&right=:v` | 两方案共同准则比较 | 路径图、历史 / 原件定位、返回两页 |

对象详情优先使用 URL 驱动的右侧抽屉：`?panel=node&id=:n`、`?panel=evidence&id=:e`、`?panel=test&id=:t`、`?panel=decision&id=:d`。复制链接后可直接复原抽屉；窄屏抽屉改全屏层，保留返回原页。对话框只承载一次明确事务：新建页、从旧版分支、确认 AI 候选、合流成新页、改权限、隐私删除、最终导出。顶部轻提示只确认“已保存草稿”等短暂事实；冲突、权限拒绝、原件损坏和引用失效必须留在页面中直到用户处理。自然语言问答可用聊天气泡承载提问与简短回答；带证据、可采纳变更或决策的输出必须是结构化卡片，不得塞进一次性气泡。

## 2 逐页功能、入口出口与交互载体

### R01 项目书架 P0

- **页面组件**：项目卡（标题、最近活动、当前章/页、待处理候选数、待审阅数）、项目筛选、最近访问、显式“新建项目”、容量/同步状态。卡片无权限时不展示名称。
- **读/写**：读本人可见的项目摘要与待办计数；仅“新建”进入 R02，卡片打开不写业务版本。浏览偏好可存本地。
- **入口/出口**：登录落点；进入 R03 或 R12，创建进 R02。空状态用有用的“新建项目”示例，不展示虚构项目；加载骨架保留卡片尺寸。

### R02 新建项目 P0

- **页面组件**：分步表单“课题简报→阶段模板→成员与共享范围→确认”，字段包括目标、约束、截止时间、模板版本、成员角色；AI 可在侧栏建议澄清问题，但不会填成已确认事实。
- **交互载体**：这是全页向导，不塞入聊天气泡；末步对话框预览将建的项目、初始章与第一页及可见范围。取消返回书架；未提交草稿只在明确授权的本地/服务端草稿范围保存。
- **合同/权限**：创建命令带 `Idempotency-Key`；`request_id` 仅作追踪；成功响应 `project_id`、首个 `stage_id`、`page_id`、版本/草稿标识。失败原位提示；重试不能建两个项目。

### R03 项目概览 P0

- **页面组件**：项目摘要、阶段条、页路径图与等价列表、关键路径、分支与合流计数、待确认建议、最近测试、作品缩略图、来源覆盖提示、未决问题。树布局仅是视图，谱系边标签明示“承接/分支/合流/回访”；引用与对照另用非谱系关系展示。
- **入口/出口**：从书架、搜索、审阅跳入；页卡进 R05，章卡进 R04，资源进 R07，审阅进 R12，候选进 R10。可切“图/列表/最近活动”，选择只影响视图偏好。
- **写操作**：新建同阶段页或从已确认来源页建下一章页，必须打开事务对话框；拖动卡片不改变页间边。放弃路线需明确状态动作和范围预览，不删除历史。
- **状态**：没有页时显示“写研究问题/上传资料”；图加载失败可切列表；部分页受限时用“有不可见内容”而非暴露名称、缩略图或数量细节。

### R04 章概览 P0

- **页面组件**：章目标、模板与已确认活动、同章平行页网格、页状态过滤、来源与去向关系、章时间点选择器、可选“创建平行页”。每张页卡标 `page_id`、当前/历史、负责人、作品预览来源、未决点和父来源版本数。
- **入口/出口**：从阶段条、路径图、面包屑进入；页卡进 R05。新页对话框提供“完全空白”“从来源引用已确认项”“从旧版继续”三种明确起点；同章平行新页不自动与其他页建立前后边。
- **读/写**：读 `stage_id` 下当前授权的页；选择旧 `project_revision` 时返回按当前权限裁剪的 `StageViewSnapshot` 并整体只读，撤权对象及其数量不因历史时间点泄露。新页写必须带 `Idempotency-Key` 和来源版本列表；`request_id` 仅作追踪，提示若来源变化需复核。移动页到另一章不是拖拽排序，需另行定义迁移命令与审计，首版不提供。

### R05 单页工作区 P0

- **页面结构**：顶部“本页要回答的问题”、状态/分支/版本徽标与保存指示；左侧章页目录；中央节点图/列表切换；右侧对象详情/智能体工作台/本次读取范围，面板互斥但标签可切。空页主操作为“写问题”“上传资料”“引用已确认项”。
- **节点操作**：便签可转类型节点；新增节点/关系先显示类型、方向、锚点和证据要求。主树边与支持/反对/测试/引用边区分，边可由键盘/列表建立。节点详情抽屉包含作者、时间、状态、所属版本、来源和作品引用。删除草稿节点需撤销入口；已确认版本只能创建新修订，不能静默改写。
- **版本操作**：章时间点只读、页版本只读、节点在页快照中定位；版本选择器的“查看第 N 版”只改变 `v` 并进入只读；“返回当前版”恢复草稿/最新已确认版；“从此版继续”进入分支对话框，必须输入目标/变更摘要，显示源版与新路线关系。页内图与目录保留选中焦点，避免翻页后失向。
- **AI 操作**：右栏有任务输入及四个快捷动作；提交前展示版本、记忆读集、工具种类、预算。运行时显示步骤和故障，不遮住设计内容。一个运行绑定一份不可变读快照，用户更改草稿后旧候选应转“依据旧草稿修订，需重检”。
- **切换体验**：在权限内预取相邻页版本的安全读投影；切换时用目标版本骨架和版本徽标避免新旧内容混帧，恢复该版本的缩放、筛选和对象焦点。撤权立即清掉相应缓存及预览；正在执行的 AI 仍绑定旧快照，切到另一页后明确提示下一次运行使用新读集。预取不等于提交。
- **保存语义**：草稿编辑显示“保存中/已保存草稿 Rn/保存失败/版本冲突”；“已保存草稿”不等于“已确认设计决定”。拖动坐标只存视图偏好，不生成设计版本。离线编辑若未获持久化确认，明确提示本地待同步与可能冲突。

### R06 历史与谱系 P0

- **页面组件**：按时间列项目与页快照，按来源边列分支谱系，文本差异表列增删改节点/边/作品引用/决定与作者；章时间点显示当时配置与页集合。版本卡含 `page_version_id`、源版本、时间、变更摘要、是否当前、测试适用性。
- **入口/出口**：页版本按钮、项目路径、审阅意见可进入；点历史版本回 R05 的 `v=:version_id`；“从此版创建新路线”开对话框；返回当前版明确。P0 是结构化变更清单，像素级画布或文件二进制差异可列 P1。
- **边界**：历史版的“继续”不把它设为新的当前 HEAD，不删除其他分支；新页 v1 从源快照继承可编辑内容，跨阶段推进则仍建主体空白页。新路线有新的 `Page` 身份和 v1 分支基线，复制源版的可编辑节点/关系内容并分配新 ID 与来源映射；原件和证据只引用确切旧版。旧决定/测试只作历史依据，不重签或沿用通过结论。已绑定旧作品版本的测试显示“只对旧版有效”，不能把通过结果自动继承。

### R07 资源库 P0

- **页面组件**：可视化文件卡、列表视图、按章/页/方案/格式/作者/时间/版本筛选、上传队列、预览状态和封面来源。所谓文件夹是筛选视图，不是物理历史；同一原件可在多页出现，资源记录只存一份。
- **上传路径**：选择文件→预检类型/大小/许可/敏感范围→确认上传→显示“传输中/原件已保存/抽取中/可检索/需封面/失败”。上传成功后可“关联到当前页/节点”，这是独立关联动作；先上传不自动变成证据。
- **异常**：原件写失败不得显示“已保存”；预览失败可下载原件、手工封面、重试；原件校验失败时禁用下载并明确完整性错误。专业格式不能因有缩略图就暗示可编辑或工程属性已解析。

### R08 资源版本详情 P0

- **页面组件**：预览或可信封面、原件元数据（版本、哈希、MIME、大小、上传者、许可、敏感级别）、预览生成方式与失败原因、版本链、被哪些页/节点/测试引用、下载原件。原件和预览的可用状态分别显示。
- **入口/出口**：资源库、节点、证据、测试的深链；“查看引用页”回 R05 的准确版本与对象焦点；“查看旧版”留在本页切 `artifact_version_id`。换文件应新建作品版本，不覆盖旧版；更新后提醒旧测试需复核。
- **权限**：下载、预览、元数据、引用关系可分级授权；无权者不能从错误信息、缩略图、搜索摘要推断保密文件内容。失效的合法删除呈现带审计号的墓碑状态。

### R09 搜索结果 P0

- **页面组件**：输入、类型/章/版本/时间/有无权限过滤、结果列表、来源命中高亮、历史/过期标识。结果类型包括页、节点、作品、证据锚点、测试、审阅意见、AI 候选。
- **入口/出口**：全局顶栏；结果打开准确版本和对象抽屉；跳历史版前显示只读徽标。无命中显示已查范围、索引版本与“部分新文件尚未索引”，不能推断资料不存在。
- **隐私**：服务端先按项目与对象权限过滤再查询；无权文档的标题、片段、缩略图、数量都不应通过搜索暴露。

### R10 智能体运行与候选 P0

- **页面组件**：任务文本/快捷动作、当前输入版本与草稿修订、上下文读集、真实执行步骤、工具事件摘要、证据卡、未知/冲突卡、候选变更列表、成本/耗时和 `run_id`。完整日志按权限分层。
- **表现形式**：对话气泡仅用于用户问题和简短解释；证据、方法、过程批评、阶段建议必须是卡片。进度为按事件更新的步骤条，`candidate_ready` 是已校验且 pending 的界面标签，公开事件名为 `candidate.ready`；标签出现前没有“采纳”。候选卡可由读者查看；只有具决策权限者可预览提交。
- **入口/出口**：页工作台、项目待办、通知、审阅；证据卡进 R05/R08 精确锚点；确认预览成功返回新页 R05；拒绝/稍后返回原页；历史运行仍可看输入快照但不可重新提交过期候选。
- **故障**：工具超时显示已完成与未完成步骤、已验证局部结果、重试或手动继续；文档注入指令不会转为操作按钮；来源失效或权限变化禁用采纳并提供重检。

### R11 记忆与本次读取范围 P0

- **页面组件**：四层标签“原件及会话归档 / 已确认项目事实 / 版本化摘要和索引 / 本次运行上下文”；每条记忆显示来源对象、所属页版本、确认者、更新时间、敏感级别、是否当前、派生状态。默认按项目→章→页分组，图只是辅助，列表与搜索完整可用。
- **切换语义**：在本次运行面板可以勾选已授权的邻页版本、证据锚点或方法卡，排除无关摘要；按钮写“用于下一次检查”而非“切换项目记忆”。改变此读集只影响下一次 `AgentRun`，不会撤销已确认事实或更改历史。历史上下文重演明确写“按当时的版本查看”，默认不会作为当前项目事实使用。
- **冲突与过期**：过期摘要标明派生自哪个旧页/作品版本，提供“查看源版/重新生成”，不能直接一键“设为事实”；互相矛盾的证据并列。权限撤销后已打开面板刷新并遮蔽失权内容；先前运行轨迹只显示安全摘要。

### R12 项目审阅 P0

- **页面组件**：关键路径、已确认要求、证据覆盖、作品版本、测试、未验证项与 AI 建议处置；授权审阅意见按页版本/节点锚定并显示作者、时间、可见范围。AI 候选与已确认内容分组。
- **入口/出口**：项目概览、邀请/通知；点击结论沿链到 R05/R08/R10 的准确版本；回复意见返回绑定对象。无权原件仅显示“受限及可用的脱敏摘要”，不得显示缩略图。
- **权限**：默认可读共享内容并留意见，对业务图只读；获授决策权才出现确认动作。意见编辑仅作者且仍有相应权限；其他人可回复，不可改写原话。审阅页不代替设计师最终报告审校。

### R13 导出与复核 P0

- **页面组件**：输出类型、章节/路线/版本/作品范围、来源索引预览、敏感内容提示、缺失原件/失效链接清单、报告草稿编辑与署名。导出预览与最终文件带同一 `export_job_id` 和输入快照。
- **事务边界**：导出前确认源版本、许可、可见范围、未验证项和作者署名；生成异步任务，页面可回看状态和下载。若输入版本改变，旧导出仍显示依据快照，不自动伪装最新。权限不足需阻止包含受限原件的导出。
- **入口/出口**：项目导航、审阅页；成功下载并返回项目。失败可重试同请求而不重复生成不一致文件。

### R14 项目设置 P0

- **页面组件**：阶段模板及顺序、成员与角色、对象共享范围、主动建议频率（关闭/手动/事件后/定时摘要）、冷却时间、数据保留与导出权限。每项变更显示影响范围。
- **交互载体**：普通偏好用表单/开关；权限提升、共享外部人员、隐私删除必须用列出对象及后果的确认对话框。建议频率关闭不关闭权限告警与完整性错误。
- **版本边界**：模板调整不自动改历史页的所属章和来源边；权限变化使已有候选失效并刷新可见资源。删除合法敏感资料走审计化墓碑流程，普通“放弃路线”只改状态。

### R15 两方案比较 P1

- **页面组件**：明确固定左右 `page_version_id`，按共同准则列问题、证据/反例、作品、测试、风险、审阅意见和差异；缺失写“未记录”；每项可回原件。窄屏逐项切换。
- **入口/出口**：从两张页卡或历史进入；返回各原页。AI 比较摘要需与原始表并列，用户可改写或拒绝；摘要不能覆盖来源表。P0 只要求在概览分别查看两张平行页，不承诺此并列表。

## 3 事务弹层、抽屉与聊天边界

| 触发 | 载体 | 必须显示 | 确认后与取消后 |
| --- | --- | --- | --- |
| 自由提问/查证据/问方法 | 右侧智能体工作台；提问可为气泡，回答以证据/方法卡呈现 | 本次页版本、资料范围、运行进度、可打开来源 | 问答不写业务图；可将有类型候选送入确认预览 |
| 建平行页 | 新页对话框 | 目标章、是否有来源、空白页承诺、可见范围 | 创建新 `page_id` 与初始草稿；取消不建页 |
| AI 建议进入下一章 | 候选卡→变更预览对话框 | 来源页版本列表、拟建目标章/空白页、拟引用项、缺口、权属与有效期 | 提交成功后翻页到新页；拒绝只写处置；取消返回候选 |
| 从历史继续 | 分支对话框 | 旧版身份、现行版差异、路线目标、继承引用列表、旧测试限制 | 新路线有新的稳定页/分支身份及来源边；取消留在历史只读 |
| 多来源合流 | 变更预览对话框 | 每个来源的确切版本、共有/冲突证据、拟建空白页和关系类型 | 建新页并保留所有来源；不能把原分支压平或删掉 |
| 编辑节点和关系 | 对象抽屉或行内编辑 | 节点类型、证据锚点、作者、草稿修订；关系方向/类型 | 草稿修订递增；若已确认版，先创建工作草稿 |
| 作品上传 | 上传侧抽屉/队列 | 授权、许可、文件大小格式、敏感级别、原件与预览独立状态 | 原件落库后生成 `artifact_version_id`；取消前已写入内容需按保留策略处理 |
| 资源/证据/测试查看 | 可深链对象抽屉 | 原件版本、来源定位、访问权限和失败状态 | 只读查看不写业务版本 |
| 审阅意见 | 对象抽屉中的独立评论区 | 锚定页版本/节点、可见范围、作者时间 | 保存意见事件；不改页节点内容 |
| 导出 | 全页复核加最终确认对话框 | 版本范围、权限、许可、缺失/失效来源、署名 | 创建导出任务；取消不改变项目事实 |
| 隐私删除/权限提升 | 强确认对话框 | 受影响原件、引用与可见范围、审计记录 | 独立受控流程；历史回溯功能不能替代合法删除 |

弹层不可叠弹层：需要在确认过程中查看证据时，预览保留为稳定后台状态，证据在相邻抽屉或新标签打开，返回时重新校验候选有效期。关闭弹层不会隐式“接受”。键盘焦点进入弹层后被约束，关闭后返回触发按钮；错误概要可聚焦。长任务用页面/抽屉，不用阻塞弹窗等待 AI。系统通知不伪装为智能体说话气泡。

## 5 状态和错误的跨页统一规则

| 状态 | 全局/页面呈现 | 保留的安全出口 |
| --- | --- | --- |
| 草稿保存中 | 顶栏明确“保存中”；离开页面前可继续后台保存 | 不把状态显示为“已确认” |
| 草稿保存失败/离线 | 持久警示，标本地未同步更改范围 | 重试/导出本地草稿（若可行）/保留输入，禁止无提示离开 |
| 业务版本冲突 | 保留编辑内容，显示远端变更摘要与 `expected_page_version_id` | 比较、复制为平行草稿、重新应用；绝不静默覆盖 |
| 历史只读 | 顶栏与内容区双重标识，编辑控件禁用 | 返回当前版、从此版继续 |
| AI 候选过期 | 卡片持续显示原输入版本与变更原因 | 查看当时上下文、重检、从旧版建分支 |
| 无证据/资料未索引 | 说明已查范围、未纳入文件及索引状态 | 补资料、稍后重试、人工记录待验证 |
| 来源失效/被合法删除 | 精确引用处标墓碑与失效时间；不显示原文 | 查看原决定的历史说明、请求有权者处理 |
| 无读取权限 | 详情抽屉显示受限原因，不含标题、缩略图、原文 | 请求授权或返回共享摘要；前端和 API 双重限制 |
| 预览失败但原件完好 | 卡片为“原件已保存，预览未生成” | 下载原件、上传封面、重试转换 |
| 原件损坏或不存在 | 明确“完整性错误”，不提供假预览 | 联系项目维护者，保留审计与引用状态 |
| AI 部分失败 | 步骤条说明成功/失败工具与局部结果边界 | 有限重试、手动继续、取消；不出现完整结论按钮 |
| 双击提交/断网重试 | 保留原 `Idempotency-Key` 与相同正文；`request_id` 关联状态，完成后复用同一结果 | 不重复创建页、边、作品或意见 |

图和列表用同一数据及状态枚举；颜色只是辅助。项目在任何页面应能用项目名、章、页、版本、对象 ID 找回当前位置。响应式界面可把右抽屉升为全屏层，但“返回原页”的准确版本和对象焦点必须保留。对于合法隐私删除后的链接，不应回退到另一版原件假装引用仍有效。

## 6 与 UI 白皮书 1.3 的对应

UI 白皮书 1.3 延续原有定位、专业角色、非线性页图、AI 候选与审阅边界，并按以下约束微调。逐页细节以本规范为交接合同：

1. **信息架构与导航明确路由表与四坐标说明**：项目/章/页/业务版本/AI 读集/对象焦点不能互相隐式改动。明确 `?v=` 是只读历史，`?panel=` 是可深链详情；图和列表共用稳定 ID。
2. **智能体工作台明确对话载体规则**：简短问答可用气泡；证据、方法、候选、阶段建议为结构化卡；运行进度用步骤条；事务确认用对话框；对象追源用抽屉。尤其不要把“候选已准备”画成“项目已改变”。
3. **单页工作区明确双版本显示**：已确认 `page_version_id` 与草稿 `draft_content_revision` 同时可见；AI 运行绑定两者。草稿变更会使旧候选过期。拖动坐标是视图偏好，不进设计版本账本。
4. **翻页与分支明确事务语义**：切换历史仅查看；从旧版继续要创建新路线和确切来源边；多来源合流建新的空白页。成功响应后才播放翻页动效，提交冲突不应有“已翻页”假反馈。
5. **资源库与专业文件区分三态区别**：原件已保存、派生预览成功、索引可检索相互独立；上传/预览/证据确认各有操作和失败回退。测试只能绑定 `artifact_version_id`。
6. **本次读取范围/记忆目录**：解释四层记忆，允许在权限内调整下次 AgentRun 的读集，显示每项版本和原始来源；该操作不是对权威项目事实的直接写入。历史读集可复现，但默认不代表当前事实。
7. **项目审阅与协作明确权限矩阵**：审阅意见可写、设计图只读；授予决策权才可确认；失权后缩略图、搜索摘要和已打开抽屉同步遮蔽。意见与候选分别标明作者身份。
8. **设计验证增加最小定量口径**：区分任务成功、误入历史、错误确认、越权展示、重复写入和恢复成本；对尚未测得的性能与体验用“待测”，不写预期提升为结果。

### 6.1 需要技术规范消歧的接口边界

- 产品稿规定一次 `AgentRun` 绑定 `page_version_id`，又规定工作草稿自动保存而正式确认点才形成 `PageVersion`。若 AI 能读草稿，就必须附 `input_draft_content_revision` 与 `draft_content_hash`，否则草稿编辑后无法准确判定候选是否过期。UI 建议同时显示“已确认基底 Vn + 草稿 Rn”，且旧运行只重演当时的读集。这是补充合同，不要求改锁定的产品稿。
- 产品稿第 5.2 节用团队评论描述完整场景，F13 把团队评论与交接列 P1；首版 UI 应以 F13 优先级为准：P0 有成员身份、分配页访问、授权审阅意见；P1 再上线普遍团队页/节点评论与交接。若课程演示必须同时展示两位设计师的评论，应在范围评审时显式升级 F13，而不是在 UI 文案里悄然当 P0。
- `PageEdge` 的“跨阶段承接/同阶段对照/回访”应有服务端类型与无环谱系约束。UI 可显示任意设计活动往返，但不能让拖动线条自行决定新版本的因果关系。页版本的阅读权限与证据原件权限还需分别检查。
- 阶段建议的四档频率属于用户偏好；关键安全/权限/完整性错误不能随“关闭主动建议”消失。这需要 UI 通知类别与 AI 主动建议类别分离。

| T04 历史分支 | 查看旧版并“从此版继续” | 新页 v1 继承可编辑内容并记录源映射；旧路径、原测试、意见保留；不自动改成最新 |
| T05 草稿版本竞态 | AI 运行开始后编辑草稿或改变权限 | 候选标过期或失权，不可直接采纳；数据库无候选业务写入 |
| T06 幂等与冲突 | 使用相同 `Idempotency-Key` 和相同请求正文重试；`request_id` 仅追踪 | 只有一张新页/一组边；冲突时内容留在预览且说明未创建 |
| T07 记忆切换 | 在本次读集勾选一条邻页证据、排除旧摘要 | 运行轨迹能列实际读集和版本；切换不改已确认项目事实 |
| T08 权限隔离 | 审阅者无原始访谈权限但有脱敏摘要 | 搜索、缩略图、深链、导出均不泄露原件；可看到允许的摘要与限制原因 |
| T09 原件与预览 | 上传不支持的专业工程文件，强制预览失败 | 原件仍可取回；预览失败和索引不可用分别标识；测试只能指具体作品版本 |
| T10 无障碍路径 | 仅键盘/列表完成找证据、看历史、确认具权候选 | 焦点顺序可见、关系有文字、抽屉返回焦点、关键状态可被读出 |
| T11 角色确认边界 | 有审阅权但无项目决策权的评审打开候选 | 可以追源与留意见，不出现可执行的“确认创建新页”操作 |

建议先做专家任务走查，再以 3–5 名设计师和 1–2 名授权审阅者进行形成性测试。报告每项的成功/失败、误操作、停顿、回退步骤和原话，不用小样本声称统计显著性。性能目标应在具体设备、网络、数据规模与图节点数量确定后测定；目前不能把建议动画时长或页面响应写成已达成指标。

## 8 本规范的交付边界

本规范提供 UI 层可落地的页面与交互合同，未选择最终前端框架，也未验证 D/E 盘旧代码中的路由、服务、权限与性能。实施时仍需领域 API 的对象模型、错误码与事件格式，才能将这些页面从设计稿变成可运行流程。产品白皮书保持锁定；若发现产品级冲突，应以独立的设计变更记录提出，不直接改其文本。


## 9 并行工作和信息密度的页面落点

本节规定 R05、R06、R10、R11 的默认布局与跨页状态。用户面对的是一个任务和一组可追溯结果，界面不同时展开四个角色的聊天窗口。共享页眉保留项目 / 章 / 页、当前版本、草稿状态与权限；只在当前任务相关处显示运行状态。

| 页面 | 默认首屏 | 按需展开 | 必须持续可见的状态 |
| --- | --- | --- | --- |
| R05 单页工作区 | 中央图或列表为主体，左侧可折叠页目录，右侧默认只开一个任务栏 | 对象详情、智能体、读取范围三者互斥；窄屏变全屏层 | 已确认 Vn、草稿 Rn、保存结果、历史只读 |
| R06 历史 | 时间线和来源谱系的简图，默认展示选中两版的结构差异 | 节点级差异、测试适用性、来源详情 | 正在看的确切版本与返回当前入口 |
| R10 运行 | 顶部任务与输入快照，中部进度/结果卡，底部一个主要操作 | 工具日志、费用、未调用职责、原始结构化输出 | 运行状态、证据缺口、候选是否可提交 |
| R11 记忆 | 按项目/章/页组织的来源列表与本次读集摘要 | 图视图、索引详情、历史读集 | 选中读集只用于下一次运行、每项来源版本 |

**R05 右栏细节。** 初始宽度以节点图和正文阅读优先；打开对象抽屉时，智能体栏收起并保留一个带状态的小入口。运行可在后台继续，切换到 R10 看完整轨迹；回 R05 只显示“正在查证据”等简短状态和结果数。页面卡片按任务层级显示：问题与节点为一级，来源和作品为二级，工具日志为三级。移动画布和选中节点不触发新的 AI 运行。

**R10 多职责并行。** 步骤条只显示实际执行的“澄清任务、查证据、选方法、检查进度”；并发步骤可并列，依赖步骤显示等待原因。局部结果用明确的“已完成 2/3 项”及受影响结论；晚到输出仅在运行轨迹新增记录，不改用户已看到的候选卡。单个对外答复使用思诺统一声音；专业证据、方法及建议各有自己的结构化卡，不排成人格聊天剧场。确认弹层从候选卡打开，列当前版与输入版差异、来源失效和权限；成功响应后才进入新页。

**R11 读集与撤权。** 读集编辑显示对象名称、版本、敏感级别、纳入理由、预计片段量；受限项只给安全说明，不预览标题或缩略图。提交“用于下一次检查”只保存用户的选择偏好，下一次运行仍由服务器按当时权限重算。运行中撤权时，R05/R10/R11 的受影响卡同时失效，R10 的历史轨迹只保留安全摘要。可见的候选随之标为“需要重新检查”。

**建议频率。** R14 的“关闭/手动/事件后/定时摘要”仅控制主动阶段建议；用户直接请求“检查方案”始终可运行。权限、保存失败和原件完整性告警独立显示。频率设置界面提供一行实际效果示例，不展示复杂调度参数。

### 9.1 更简洁的文案与视觉约束

导航标签用工作语言：“项目”“阶段”“页面”“资料”“审阅”。智能体入口用“查证据”“找方法”“检查方案”“建议下一步”；显示角色职责而不拟人化。主操作每个视图只突出一个，次要操作收进相邻菜单；危险或影响版本的动作必须保留可见文字和确认预览。色彩优先区分业务状态与 AI 候选，不能靠颜色区分版本；长证据提供行距和来源定位，卡片折叠不藏掉证据级别。低动效偏好关闭翻页动画后，切换语义、焦点和状态仍完整。

**文案示例。** 空页写“这页想回答什么问题？”；过期提示写“这条建议基于草稿 R4；当前是 R6。查看差异或重新检查。”；证据不足写“当前可访问资料只有一位参与者的夜间使用记录。可先记录假设，再补充观察。”；确认按钮写真实操作，如“创建需求定义页”。避免每条结果都重复解释“由人决定”，该边界由一次明确的确认操作表达。

### 9.2 新增验收任务

| 用例 | 操作条件 | 通过条件 |
| --- | --- | --- |
| T12 并行步骤 | 同一运行并行查证据和找方法，随后过程检查 | 步骤条能分辨并行、等待和局部失败；未执行职责不出现 |
| T13 撤权联动 | R05 打开资源、R10 订阅流、R11 勾选读集后撤权 | 三处内容及缓存同时遮蔽，候选不可提交，重新打开仍无泄露 |
| T14 信息密度 | 在窄屏从节点到证据、运行、历史再返回 | 一次只开一个详情层；原页、版本和焦点准确恢复 |

## 10 与技术规范 1.1 的交叉核对

R05 的草稿 CAS 对应技术第 14.2 节；R10 的独立任务输出与晚到隔离对应第 14.1 节；R11 撤权与读集重算对应第 14.3 节；R14 建议频率属于展示/通知策略，不能触发领域推进。DeepSeek 只出现在服务端模型适配器，任何 UI 页面均不输入或保存 API 密钥。UI 仅显示可理解的当前模型任务与费用摘要，不暴露完整敏感请求。产品白皮书 2.1 的 P0/P1/P2 范围保持不变。
