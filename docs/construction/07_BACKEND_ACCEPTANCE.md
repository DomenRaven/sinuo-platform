# 07 后端验收、故障注入与证据施工合同

状态：施工基线，2026-10-30。本文件验收可运行的后端 P0。UI 与真实用户可用性测试由后续阶段完成；后端开发可以通过 API、CLI 和集成测试独立交付。文档齐全、占位端点、模型自评和 FakeProvider 的漂亮文字均不能替代本文件要求的运行证据。

## 完成定义

P0 后端完成要求：从空数据库经迁移启动；创建项目与平行页；保存版本和原件；形成可定位证据；按任务调用最多三种职责；生成合法候选；人工提交一次性生效；支持历史分支、授权审阅、导出和备份恢复。失败路径保留准确状态，权限与版本不变量在独立连接/进程并发下成立。没有 UI 不等于没有完整用例，接口与 CLI 应足以重演这条链。

每张工作卡的 `done` 依据为：目标行为测试通过、必要失败例已执行、接口/迁移一致、独立审查无未处理阻断项、证据路径可访问。未实现的能力显式标记 `not_implemented` 或返回安全不可用状态；不得通过默认成功、固定示例输出或绕过权限来满足验收。

## 统一测试资产

在 `tests/fixtures/` 建可公开、无真实个人信息的固定演示项目“夜间取物辅助产品”。所有虚构数据标记 `synthetic=true`，不能在报告中称为真实用户研究。项目至少包含：两个同阶段平行页，三个正式页版本，两个内容不同但同名的作品版本，一份文本型 PDF、一张 PNG/JPEG、一个受控 GLB、一份只保存不转换的专业格式样例；访谈/观察片段有确切页码/区域，方法卡含来源与适用条件。专业格式样例必须是合法生成的真实文件或明确标记的不可解析测试字节，不能用改扩展名伪称 SolidWorks 文件解析成功。

至少建立四种认证身份：主设计师（可编辑且有决策权）、团队成员（分配页可编辑但无决策权）、评审（共享内容只读并可留意见）、另一项目成员（跨项目不可见）。另有被限制的原始访谈及可共享脱敏摘要。运行测试在独立临时数据库和对象目录，绝不指向 D/E 原项目或用户真实资料。

FakeProvider 输出可控的正确、无证据、冲突、非法 Schema、超时、权限诱导和晚到结果。真实模型样例单独标记 `live_model`，须显式开启并配置本地预算，默认测试不发生付费调用。不同模型下的提示词与结果都记录版本，不混在确定性事务回归中。

## 建议测试组织与命令

```text
tests/
  unit/            # 领域不变量、Schema、哈希、DAG与预算纯逻辑
  integration/     # 真实SQLite、API、对象库、迁移、Outbox
  concurrency/     # 独立连接/进程、barrier协调、租约与冲突
  recovery/        # 崩溃重启、备份与恢复、删除墓碑
  acceptance/      # 纵向业务链、权限矩阵、导出manifest
  fixtures/
```

目录可以随骨架渐进迁移，保持测试名称和验证目标清楚。统一注册 `integration`、`concurrency`、`recovery`、`live_model` marker。Windows 下使用独立临时路径及进程启动方式，不依赖 fork 或隐藏共享全局变量。

```powershell
python -m pytest -q -m 'not live_model'
python -m pytest -q -m concurrency
python -m pytest -q -m recovery
python -m ruff check .
alembic upgrade head
```

上面的迁移命令只对明确配置的空测试库执行。交付脚本应创建隔离数据根并导出所用配置名称，避免操作者误用真实库。基线命令、退出码、commit/工作树状态、依赖锁摘要、操作系统、SQLite/转换器版本和测试数量写入证据报告；截屏仅作补充，不能替代退出码和断言结果。

## 领域、版本与事务验收

| ID | 操作与故障 | 通过条件 | 主要映射 |
| --- | --- | --- | --- |
| A01 | 从空库创建项目、阶段、两张同章页 | 首版/草稿/成员初始化原子完成；两页没有自动先后边 | F01/F02 |
| A02 | 修改节点类型、内容与支持/反对边，再保存为版本 | 内容 CAS 递增；旧快照内容哈希不变；边端点合法 | F03/F08 |
| A03 | 两个独立连接基于同一草稿修订同时保存 | 一次成功、一次 409；数据库是其中一个完整结果，不混合或丢失 | INV-04、TX-01 |
| A04 | 保存确认版时另一个连接修改 HEAD 或草稿 | 预条件失败则整个事务回滚；无半个版本/回执 | TX-02 |
| A05 | 从旧 V2 分支，而源页已到 V4 | 新 Page/v1、新节点 ID 与 origin 映射；源 HEAD 不变；旧测试不自动通过 | F05 |
| A06 | 从 A V3、B V1 合流进入下一章 | 新页主体空白，两条确切来源边、显式引用和决定同事务 | F04/F09 |
| A07 | 拖动个人布局，再提交内容未变的候选 | 布局只改个人视图修订，不导致内容候选过期 | INV-04 |
| A08 | 查询历史项目/章/页/节点，再退出 | 当前 HEAD、草稿、原件、ProjectRevision 数量不变 | INV-02 |
| A09 | 替换作品 V1→V2，旧测试仍存在 | 测试始终绑定 V1；V2 测试适用性待复核 | F06/F08 |
| A10 | 双击同一提交，响应丢失后原键重试 | 相同对象与响应引用；同键异体 409；事务效果一次 | 幂等合同 |
| A11 | 两名具权者用不同键同时确认同一候选 | 只有一方消费成功；另一方候选已处置；一张新页/一个决定 | INV-07 |
| A12 | 预览后篡改 user_patch、来源或 preview_hash | 提交拒绝，业务零写；重新预览后方可提交 | 预览绑定 |
| A13 | 事务写到页/决定后注入异常 | 页、边、候选消费、Audit、Outbox、Receipt 一并回滚 | INV-06 |
| A14 | 更正已确认要求、决定、测试 | 追加 supersedes 关系，原记录可读且不被静默重写 | INV-01 |

竞争测试用 barrier 或明确调度使两个独立连接真的重叠；仅顺序执行两次函数不算并发证据。至少 A03、A10、A11 在重复运行中稳定通过；初始建议 20 次，若随机失败，先定位竞态，不能以重试整套测试掩盖。

## 工作流、消息与任务恢复验收

| ID | 操作与故障 | 通过条件 |
| --- | --- | --- |
| W01 | 证据与独立方法并发，批评依赖两者 | 批评开始时两项结果均存在；各任务独立槽；计划实际调用数≤3 |
| W02 | 缺必需证据、非法依赖或循环 DAG | 启动前拒绝非法图；依赖失败阻断下游；不产出完整阶段推进候选 |
| W03 | 三职责运行中某任务消费更多 token/工具额度 | 预算原子预留，总量不超限；未计量费用显示待核，不能归零 |
| W04 | 候选已发布后旧任务返回或旧租约 finalize | 输出进入 discarded_late/安全日志；候选、预览及业务不变 |
| W05 | Worker 认领后崩溃，租约过期由新 Worker 接管 | fencing_token 增加；旧 owner 续租和完成均失败；仅一个有效结果 |
| W06 | 业务事务成功后通知前崩溃 | 重启轮询 Outbox 发现任务并完成；无需进程内通知才能恢复 |
| W07 | 派生文件完成但 consumer receipt 前崩溃 | 重试可重用或重新计算，最终一个有效登记；无重复业务版本 |
| W08 | 模型超时/429/5xx，随后取消运行 | 有界退避；总 deadline 生效；取消后晚到结果不发布；实际用量保留 |
| W09 | 同一 Outbox 重投两次、两个消费者各自处理 | 同消费者效果一次；不同消费者有独立 receipt；一方失败不误标另一方 |
| W10 | SSE 断线、重连、重复和过期游标 | 持久事件可回放，event_id 去重；过期游标要求快照重取，不丢业务结果 |
| W11 | 切换页/分支时旧运行继续 | 旧运行读集保持原快照；新运行另建 ID，不被全局当前页串线 |
| W12 | 新检索结果进入运行，随后索引重建 | 实际读集 manifest 可按原件版/锚点重建；不声称重新搜索等于复现 |

FakeProvider 验证控制逻辑后，再选择一条真实 DeepSeek 小预算任务验证传输、结构化输出、用量与错误映射。401/402 配置类错误不能进入无期限重试；真实 key 不进入测试 fixture 或证据附件。

## 权限、存储与安全验收

| ID | 操作与故障 | 通过条件 |
| --- | --- | --- |
| S01 | 未登录、过期会话、禁用账号请求业务端点 | 401；无业务写；退出/重置后的旧令牌失效 |
| S02 | 伪造 actor/role、嵌套跨项目对象、直接猜 ID | 403/404 安全响应；不泄露标题、计数、磁盘路径 |
| S03 | 评审确认候选或团队成员修改别人意见 | 按动作权/作者/当前授权拒绝；前端可见性不影响服务端结果 |
| S04 | Cookie 修改请求缺 CSRF 或来自未授权 Origin | 拒绝；合法同源会话正常；不开放通配凭据 CORS |
| S05 | 运行中撤权后重连 SSE、搜索、下载、看旧导出、回放幂等结果 | 新受控读取均重新授权；无受限正文、标题、缩略图或回执泄露 |
| S06 | 提示注入要求读任意路径、SQL、调用确认命令 | 工具白名单/Schema 拒绝；业务对象不变；记录安全错误 |
| S07 | 文件名含路径穿越、扩展名与内容冲突、超额/截断上传 | 不越出数据根；票据明确失败/隔离；未登记字节不可引用 |
| S08 | 原件落盘后登记失败、登记与 GC 并发、旧 GC 迟到删除 | pin/登记与 GC claim 互斥；新 generation 不受旧 GC 影响；无已登记对象被误删 |
| S09 | 图像超像素、PDF 超页数、GLB 外部资源/转换超时 | 资源限额生效，子进程停止，原件仍可取回；状态真实 |
| S10 | 同名两个原件及同项目相同内容去重 | 业务版本独立；哈希正确；权限不会随物理共享扩大 |
| S11 | 中文短词/长词、无命中、待索引、旧版默认排除 | 结果定位正确，已查范围准确；无权片段不进模型上下文 |
| S12 | 隐私删除后浏览旧页、旧候选、预览、索引、导出 | 只见墓碑与安全说明，不能换版假装引用有效 |

将测试故意写入的秘密字符串作为 canary，在 HTTP、SSE、日志、导出及生成文件中检查是否泄露。canary 是合成数据，不用真实 key/访谈做安全测试。安全测试清单按明确威胁执行，不能用“模型承诺不会泄露”作为通过条件。

## 审阅、建议频率、导出与恢复验收

| ID | 操作与故障 | 通过条件 |
| --- | --- | --- |
| R01 | 共享路径留意见，作者 CAS 修改、其他人尝试修改 | 准确锚定版本；只有作者且仍有权时修改；审计可查 |
| R02 | 主动建议设置关闭、手动、事件后、定时摘要 | 关闭/手动不自动建 run；事件/定时遵守冷却与去重；直接请求可运行；权限/完整性告警独立 |
| R03 | 导出指定路线与版本，期间源 HEAD 变化 | 输出仍标确切输入 manifest；包含路径/来源/作品清单/报告草稿；不伪装最新 |
| R04 | 导出前后撤销某原件权限 | 生成与下载按当前权限复核；旧产物不成为受限内容旁路 |
| R05 | 备份含分支、作品版、证据、审阅、处置与 ACL 的项目，再恢复到新空目录 | schema/外键与原件哈希完整；读链可复现；会话失效；派生可重建 |
| R06 | 用早于隐私删除的备份恢复 | 应用最新墓碑后方可开放；缺最新删除清单则保持离线并报告限制 |
| R07 | 在运行中备份及恢复未完成 Outbox/Job | 使用一致性数据库快照；旧租约失效，任务幂等恢复；无重复页/决定 |

导出 P0 先冻结可读 Markdown、JSON manifest 和原件引用清单，ZIP 是否包含原件由显式选择与权限决定。报告草稿中的未验证项保留标识；自动完善设计论证属于 F23/P1，不混入首版确定性导出。DOCX 导出可以作为适配器增加，但不能成为后端主链的隐式前提。

## 产品功能追踪

F01–F12、F16–F21 是本轮 P0 范围；F13 团队评论交接、F14 双方案比较、F15 更多格式、F22 聚类、F23 方案批评/报告辅助为 P1；F24 实时共编、自动工程结论、全面知识图谱为 P2。F07 的自动预览须包括图片、PDF 与 GLB 一种 3D；只存 GLB 而没有可用预览尚未完成 F07。F09 包含频率设置及其后台调度行为；F10 包含真实运行账本与处置链；F20 必须证明读集切换和权威事实分层。

当前初步骨架只覆盖其中的基础子集。接手者先运行基线测试并在工作池标注实际完成范围，再实现其余任务。不得因已有同名类、空路由或静态 fixture 而把整个功能标 done。

## 客观模型评测与最终证据

冻结 10–20 条带确切来源版本的任务，覆盖简报澄清、证据冲突、方法适用条件、阶段缺口和无证据。比较 B0 单助手、B1 规则加单助手、M1 路由加专责能力，使用同模型、资料、工具权限及总预算，每题重复 2–3 次。报告有效引用率、无据断言、越权/写入拦截、过期候选拦截、人工修改量、任务完成、p50/p95 时延、token 和费用；公开任务分母、失败样本与成本计量版本。工程控制由确定性测试判定；“设计有用性/自然语言质量”按固定量规由人盲评，模型自评只作辅助。

最终后端交接至少包含：生成的 OpenAPI、迁移从空库与已有基线升级结果、测试摘要和失败处置、一个可重演演示项目及脚本、C/S/W/R 故障证据、一次备份恢复报告、运行账本样例、依赖/转换器版本清单、真实模型已测/未测状态，以及面向后续 UI 的响应/错误/状态样例。若缺真实 key、转换器或授权样例，完成其他部分并把对应验收明确列为待运行，不降低判定标准。
