## 2 依赖方向

允许：`api` → `application` → `domain`；`infrastructure` 实现 application/domain 的端口；`workers` 调用 application 端口，不直接拼业务 SQL 以外的捷径；`agents` 只通过只读工具网关读业务，只写运行域。

禁止：`domain` 依赖 FastAPI、SQLAlchemy 会话、文件系统或模型 SDK；`agents` 持有业务写 Session 或调用确认命令；路由函数里直接 `BEGIN`；在 `write_uow` 内发起网络、模型或文件转换。

## 4 深层机制速查

| 机制 | 做法 | 合同 |
| --- | --- | --- |
| CAS | 条件 `UPDATE ... WHERE revision=:expected`，看 rowcount | `03` 幂等与条件更新 |
| 写事务 | `write_uow`：`BEGIN IMMEDIATE`，块内禁止自行 commit | `03` 事务矩阵 |
| 业务与消息 | 候选消费、业务行、审计、Outbox、回执同一事务 | `03` 预览绑定；`04` 事件信封 |
| 重复消息 | 消费者去重表，按事件 ID + consumer 幂等 | `05` Outbox |
| 过期工作者 | 认领时 fencing token 递增；完成时校验 token、owner、状态、截止时间 | `05` 租约 |
| 迟到模型结果 | deadline 之后的返回丢弃，只留安全诊断 | `05` 合成与晚到；骨架 `DagRunner` 已覆盖内存情形 |
| 独立输出 | 每个专责一个结果槽，协调者单点写入 | `05` 分工 |
| 权限 | 工具、外发、SSE、下载、导出、预览、提交各自重校当前权限与 access_epoch | `06` 撤权 |

## 术语与当前代码映射

产品/技术文稿中的模型适配层 ModelAdapter，在施工代码公开接口名为 ModelProvider；它不表示已有DeepSeek实现。骨架 InputSnapshot/SpecialistResult 是内存DTO，不等同于未来持久 ContextSnapshot/AgentResult、读账本或业务ACL。实现者按冻结合同扩展，避免因名称相似把基元记为整模块完成。
