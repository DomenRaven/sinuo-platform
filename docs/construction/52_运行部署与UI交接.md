# 52 运行、部署与 UI 交接

版本：2026-10-30。本文件给后端实现和后续 UI 使用。当前可运行的只有骨架；标“待 T0x”的配置还没有代码。

## 1 本地启动

在仓库根：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[dev]"
Copy-Item .env.example .env
.\.venv\Scripts\alembic upgrade head
.\.venv\Scripts\uvicorn sinuo.api.app:create_app --factory --host 127.0.0.1 --port 8000
```

`/healthz` 只表示进程存活。`/readyz` 在迁移版本等于 `0005_stored_objects` 且已注册的表都存在时返回 `scope=foundation`，否则 503。`scope=foundation` 不是整个产品就绪。启动不会自动建表。本地身份路由在 `/api/v1/session` 与 `PATCH /api/v1/projects/{id}/access`。项目、草稿、确认版本和历史在 `/api/v1/projects` 与 `/api/v1/pages`。

测试临时目录不要放进用户文档库。日期按执行日替换：

```powershell
$tmp = "_施工文件/2026-10-30_codex/99_临时文件"
New-Item -ItemType Directory -Force $tmp | Out-Null
$env:PYTHONDONTWRITEBYTECODE = "1"
.\.venv\Scripts\python -m pytest -q -p no:cacheprovider --basetemp "$tmp/pytest"
.\.venv\Scripts\python -m ruff check src tests migrations
```

默认 pytest 排除 `live_model`。

来自 `src/sinuo/config.py` 与 `.env.example`。前缀 `SINUO_`。

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `ENVIRONMENT` | development | 当前仅环境标签；认证/生产隔离待 T02 实现并测试，不声称此字段已执行认证防护 |

## 4 迁移、worker、备份

迁移只对配置里写明的库执行，先备份再升级。交付脚本必须打印所用配置名和数据根。降级只在该变更的 downgrade 已测试时使用。

Worker 是独立进程，使用自己的 Session。停机时停止认领新任务，正在持有的租约到期后可由其他进程接管；不要在停机时把未完成投递标成成功。

备份与恢复的通过条件在 `06` 与 `07`：同时恢复数据库和原件清单；恢复后权限、墓碑和已生效的隐私删除仍然有效；未完成的 Outbox 可以重投，不能把已消费事件再执行一次业务写入。

## 5 模型

密钥只放服务端环境变量。默认测试不调用 DeepSeek。打开真实调用前要同时具备：用户授权、`MODEL_ENABLED=true`、密钥、模型名、本地预算。请求体和响应里的原文按 `06` 的外发政策过滤，不写入信息日志。

## 6 UI 交接合同

G4 通过后交给 UI 阶段，本阶段不画页面。UI 只消费下列材料：

- 从 FastAPI 导出的 OpenAPI，每个端点至少一个成功例和一个关键失败例。
- 稳定 ID：`page_id` 与 `page_version_id`、`artifact_id` 与 `artifact_version_id` 分开。提交使用确切版本，不用 `latest`。
- `04` 的错误码与重试约定。前端不根据 HTTP 状态发明新语义。
- SSE 事件信封：事件 ID、类型、schema 版本、项目、对象引用。断线用 `Last-Event-ID` 续传。
- 权限投影只决定显示。每次提交、下载、导出和流重放仍由后端重校。
- `07` 的合成夹具“夜间取物辅助产品”，全部 `synthetic=true`。

页面对端点：R01–R15 的页面定义在 `docs/reference/思诺智能体辅助设计平台UI页面实施规范_v1.1.md`。后端按 `04` 的端点清单提供数据，不在本文件重画布局。实现时在 OpenAPI 的 tag 或描述里注明主要服务的页面编号，缺页就标未覆盖，不补一个空路由充数。
