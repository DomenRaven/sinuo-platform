# OXO 演示证据 · 锚定摘要速查

上传每一份后，点交付物卡片上的「锚定一段作证据」，粘贴下表对应的摘要即可。

| 文件 | 锚定摘要（复制这一列） |
|---|---|
| 01-任务与握持.txt | 细硬金属柄在湿手和握力不足时打滑、疼痛 |
| 02-研究与动作.txt | 两份记述对削皮器落在哪一类并不一致 |
| 03-要求与概念.txt | 气泡内胆因为不够直觉被放弃 |
| 04-样机专利与材料.txt | 专利没有写Santoprene牌号，也没有写模具温度 |
| 05-试用边界.txt | 公开资料没有样本量，也没有通过率 |

## 上传时的统一填法

- 许可：`public-account-summary`
- 敏感范围：`项目内`
- 勾选「允许以后的运行读取这份原件」
